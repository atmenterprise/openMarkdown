## ADDED Requirements

### Requirement: Workspace Footer Section
The system SHALL display a persistent footer at the bottom of the page containing copyright information and a Buy Me A Coffee donation link.

#### Scenario: Displaying copyright owner information
- **WHEN** the application interface is loaded
- **THEN** the system SHALL render the owner text "ATM Enterprise" linked to "https://linktr.ee/atmenterprise".

#### Scenario: Displaying Buy Me A Coffee action
- **WHEN** the application interface is loaded
- **THEN** the system SHALL render a visual button and link pointing to "https://buymeacoffee.com/atmenterpr4".
